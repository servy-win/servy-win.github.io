Why use Servy?

  • Universal Access

    Install and manage services from the desktop app, CLI, PowerShell, or embedded installers.

  • Auto-Recovery

    Automatically restart services after crashes, hangs, or unexpected exits, or execute custom failure programs.

  • Full Process Control

    Set command-line arguments, working directory, process priority, CPU affinity, and environment variables.

  • Enterprise Security

    Per-service isolation with least privilege. Run as gMSA, Active Directory, or Local System accounts.

  • Lifecycle Hooks

    Run commands before and after launch or stop, with built-in logging and timeouts.

  • Live Monitoring & Logging

    Track CPU and RAM usage, stream stdout/stderr in real time, and configure size-based or date-based log rotation.

  • Graceful Shutdown

    Stops processes cleanly with a graceful shutdown or Ctrl+C, then force-kills the whole process tree if needed.

  • Health Checks

    Detect failures automatically and get instant alerts via email, WhatsApp, webhooks, or OS notifications.

  • Visual Dependencies

    Visualize service dependencies and export configurations for repeatable deployments.

Get Started

Download the latest release from GitHub or install via a package manager:

WinGet

winget install servy

Chocolatey

choco install -y servy

Scoop

scoop bucket add extras
scoop install servy

Patch My PC

Servy is available in the official Patch My PC catalog for enterprise automated deployment and updates via Microsoft Intune and ConfigMgr.

Quick Example

You can manage services using the desktop app, CLI, or PowerShell. 

servy-cli install --name="NodeApp" --path="%ProgramFiles%\nodejs\node.exe" --startupDir="C:\apps\nodeapp" --params="server.js"

This installs NodeApp to run a Node.js server in the background with auto-startup. See additional examples and recipes for Python, Java, Go, and other runtimes.

Use Cases

Web Servers & APIs

Run Node.js, Python, Go, or Java servers that start with Windows and restart after failures.

AI Models & LLMs

Host local LLMs and AI APIs such as Ollama or Stable Diffusion as always-on services.

Background Workers

Keep message queue consumers (RabbitMQ, Kafka), and long-running workers alive in the background.

CI/CD & DevOps

Keep self-hosted build agents (GitHub Actions, GitLab Runners, Jenkins) online.

Automation & Scripts

Run PowerShell or Python scripts as persistent daemons for file cleanup, backups, or system monitoring.

Database Proxies

Run database tunnels and proxies (Cloud SQL Auth Proxy, Ngrok) as services for stable connectivity.

Remote Management Agents

Run monitoring agents and remote tools as background services for uninterrupted access.

Network Utilities & Proxies

Run DNS servers, reverse proxies (Caddy, Nginx), or VPN clients in the background for reliable networking.

Legacy App Modernization

Wrap tools that were never built as services, and give them lifecycle management and health monitoring.
