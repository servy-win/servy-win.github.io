Why use Servy?

  • Universal Access

    Install and manage services from the desktop app, CLI, or PowerShell.

  • Auto-Recovery

    Automatically restart services after crashes, hangs, or unexpected exits.

  • Full Process Control

    Set the working directory, process priority, CPU affinity, and environment variables per service.

  • Enterprise Security

    Per-service isolation with least privilege. Run as gMSA, Active Directory, or Local System accounts.

  • Lifecycle Hooks

    Run commands before and after launch or stop, with built-in logging and timeouts.

  • Live Monitoring

    Track CPU and RAM usage and stream stdout/stderr while the service runs.

  • Graceful Shutdown

    Stops processes cleanly with a graceful shutdown or Ctrl+C, then force-kills the whole process tree if needed.

  • Health Checks

    Detect failures automatically, get alerts via Windows notifications or email, and send heartbeats to ping URLs such as healthchecks.io.

  • Visual Dependencies

    Visualize service dependencies and export configurations for repeatable deployments.

Quick Example

Servy can be managed using the Desktop App, CLI, or PowerShell.

PowerShell (Elevated)
servy-cli install `
  --name="MyService" `
  --path="C:\Program Files\nodejs\node.exe" `
  --startupDir="C:\MyServer" `
  --params="server.js" `
  --enableHealth

This installs MyService to run a Node.js application in the background with auto-startup and health monitoring.

See additional examples and recipes for Python, Java, Go, and other runtimes.

Use Cases

Web Servers & APIs

Run Node.js, Python, Go, or Java servers that start with Windows and restart after failures.

AI Models & LLMs

Host local LLMs and AI APIs such as Ollama or Stable Diffusion as always-on services, with no desktop session required.

Background Workers

Keep data pipelines, message queue consumers (RabbitMQ, Kafka), and other long-running workers alive in the background.

CI/CD & DevOps

Keep self-hosted build agents (GitHub Actions, GitLab Runners, Jenkins) online and restart them automatically after a crash or reboot.

Automation & Scripts

Run PowerShell or Python scripts as persistent daemons for file cleanup, backups, or system monitoring.

Database Proxies

Run database tunnels and proxies (Cloud SQL Auth Proxy, Ngrok) as services for stable connectivity in development.

Remote Management Agents

Run monitoring agents and remote administration tools such as MeshCentral as background services for uninterrupted access.

Network Utilities & Proxies

Run DNS servers, reverse proxies (Caddy, Nginx), or VPN clients in the background for reliable local networking.

Legacy App Modernization

Wrap older console apps and CLI tools that were never built as services, and give them lifecycle management and health monitoring.

Get Started

Download the latest release from GitHub or install via a package manager:

WinGet

winget install servy

Chocolatey

choco install -y servy

Scoop

scoop bucket add extras
scoop install servy

Patch My PC

Servy is available in the official Patch My PC catalog for enterprise automated deployment and updates via Microsoft Intune and ConfigMgr (SCCM).
